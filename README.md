# Универсална система за резервации (React + Vite)

Адаптивно уеб приложение за управление на резервации, конфигурируемо за различни типове бизнеси (салони за красота, ресторанти, медицински центрове).

## 1. Архитектура и модел на данните
Системата използва декларативен конфигурационен модел (`src/data/businessConfigs.js`). Вместо твърдо кодирана логика за всеки бизнес, приложението приема конфигурационен обект, описващ:
- `workHours`: работно време (начален и краен час).
- `slotDurationMinutes`: продължителност на един интервал в минути.
- `resources`: масив от ресурси (стилисти, маси, кабинети) с индивидуален капацитет (`capacity`).

## 2. Ефективност и оптимизация
- **Мемоизация (`useMemo`)**: Генерирането на времевите слотове се преизчислява само при промяна на избрания бизнес, предотвратявайки излишни изчисления при пререндиране.
- **Бърза проверка на конфликти ($O(1)$)**: Заетите часове за избраната дата и ресурс се трансформират в `Set` структура (`bookedTimesSet`), което прави проверката за зает слот мигновена, независимо от броя натрупани резервации.

## 3. Инструкции за стартиране
1. Инсталирайте зависимостите: `npm install`
2. Стартирайте сървъра за разработка: `npm run dev`

## 4. Екип и разпределение на задачите
- **София**: Архитектура, конфигурационен модел и симулирани данни.
- **Кристиян**: Логика за филтриране на слотове, валидации и оптимизация с `useMemo`.
- **Ралица**: Потребителски интерфейс (UX/UI), CSS стилове и документация (`README.md`).
